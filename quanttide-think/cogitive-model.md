量潮认知模型（Quanttide Cognitive Model, QCM）

版本：1.1.0

状态：正式定义

所属层：认知工程 · 认知模型

前置依赖：认识论承诺（见附录 A）


——

一、定义

量潮认知模型是一个描述性的主体认知架构，从实证日志中提炼，刻画单个主体（创始人）在面对情境时，其思考过程如何被组织为范畴、关系和层级结构。

它不是规范性模型（不规定”应该怎样想“），而是结构性模型（描述”实际如何组织“）。其有效性由实在的抵抗来检验——框架在边界处是否塌缩，决定了范畴切分是否尊重了认知本身的关节。


——

二、核心范畴

模型包含六个基础范畴，分属四个层级：

2.1 情境层

范畴	定义	存在论定位
触发点（Trigger）	引发认知活动的外部或内部事件，具有明确的时间边界和指向性	本体层——不依赖主体而”发生“

2.2 情绪层

范畴	定义	存在论定位
情绪（Emotion）	触发点唤起的主观状态，是情境到办法之间的必经中介	中介层——情境不直接催生方法，必须经过情绪转化

结构性特征：情绪层是量潮模型区别于纯理性决策模型的关键。它断言：在创始人的认知中，方法不是从情境直接推导出来的，而是从情绪中生长出来的。

2.3 应对层

范畴	定义	存在论定位
方法（Method）	主体用来应对触发点的具体做法、策略或行动模式	操作层——认知转化为行动的中介
表达（Expression）	关于”如何将这个思考说出来/写下来“的元认知活动	附属类——不参与因果链，是认知的二阶反射

2.4 归宿层

范畴	定义	存在论定位
价值（Value）	方法最终服务的方向、原则或长期承诺	目的层——认知活动的最终指向
排除的形态（Excluded Form）	某条价值明确拒绝的做法，定义认知的反向边界	反向约束层——通过”不要什么“来锚定”要什么“


——

三、关系图式

四条有向关系，语义跨集一致：

触发点  ──[触发]──>  情绪
   │                   │
   └──[应对]───────────┘
                       │
                       ▼
                     方法  ──[服务于]──>  价值  ──[排除]──>  排除的形态
                       │
                       ▼
                    表达（独立反射弧）


关系	源范畴	目标范畴	语义
触发（triggers）	触发点	情绪	情境唤起情绪状态
应对（addresses）	触发点 / 情绪	方法	主体调用某办法应对当前状态
服务于（serves）	方法	价值	办法被某条价值所驱动或合理化
排除（excludes）	价值	排除的形态	价值对特定做法的否定性约束

关系约束：

• 触发 是函数性的——每个触发点至少触发一个情绪

• 应对 是多源的——方法可由触发点直接驱动，也可由情绪驱动

• 服务于 是多对多的——一个方法可服务于多条价值，一条价值可由多个方法服务

• 排除 是单向的——排除关系不可逆


——

四、跨集一致性

模型在三份日志集（default、work、fiction）中以同一副骨架部署。类名随集的主题替换，但范畴数量、关系数量和层级结构完全一致。

集	触发点	情绪	方法	表达	价值	排除的形态
default	✓	✓	✓	✓	✓	✓
work	✓	✓	✓	✓	✓	✓
fiction	✓（创作困境）	✓（待数据填充）	✓（创作方法）	✓（待数据填充）	✓（创作动机）	✓（待数据填充）

关键判断：三集是同一套本体的三个实例，不是三套不同的体系。

fiction 集中情绪、表达、排除的形态三个类目前缺少实例，这是原始数据提取粒度的问题——fiction 日志的记录格式和条目粒度与 default/work 不同，导致这些范畴在 index.ttl 中暂未显式出现。框架本身不缺这些格。若按同等粒度重新提取，缺失范畴应当同样可以被填充。

七、模型的边界

能做	不能做
描述单个主体的思考结构	描述多主体协作（需 Activity Theory 扩展）
从日志中提炼认知骨架	自动生成新价值（只能记录已有价值）
支持新条目归类	判断归类是否”正确“（需主体确认）
跨集对齐同一副骨架	预测未经历过的语境会激活什么

沉默之处：模型不声称自己是”人类认知的普遍结构“，它是对一个特定主体的认知架构的显式化。其可迁移性限于与该主体认知结构相似的个体。

附录 A：认识论承诺（前置假设）

量潮认知模型预设了以下认识论立场：

1. 知识是情境化的——不承认脱离触发点的”抽象知识“

2. 认知是价值驱动的——方法的选择由价值约束，而非中立优化

3. 认知有反向边界——”不要什么“与”要什么“同等重要

4. 情绪是认知的必要环节——理性应对的源头是情绪而非逻辑

5. 结构是实在的投影——范畴切分不是约定俗成的标签，而是对认知本身关节的揭示
