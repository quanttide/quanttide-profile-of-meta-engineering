# quanttide-profile-of-meta-engineering

量潮元认知快照记录

本仓记录元工程领域**当前最新**的元认知档案：此刻对「一件事如何被认出来、如何拆成可执行单元」的最新认知。

## 定位

快照式——只放当前最新的一份。认知更新时，文件被替换而不是并存；旧版留在各自的来源仓与日志里，本仓不做版本堆叠。

档案按主体分目录，一个主体一个目录：

| 目录 | 记什么 |
|:--|:--|
| `quanttide-think/` | 认知骨架本身：量潮认知模型（QCM） |
| `quanttide-founder/` | 这副骨架在创始人三个集上的部署 |
| `quanttide-agent/` | 智能体一侧的档案 |
| `quanttide-relation/` | 主体之间关系的档案 |

## 概述

本档案的主要功能是记录一个问题如何以业务意图、哲学阐述、数学实现、代码实现的方式，分解成可以人机交互完成的任务单元。

业务意图说清这个问题为什么做、最终要什么；哲学阐述把它放回本体论坐标，列清有哪些东西存在、各归哪一类；数学实现把它写成可判定的条件和可核对的依赖；代码实现把这组条件和依赖落成人和智能体都能领取、都能判完成与否的工作步骤。四层写的是同一件事：一句含糊的需求，怎么走到一组算得出完成与否的单元。
