# 咨询：意图（intention）

**本仓收什么**：这个域要到哪去。未来·自我类。

**现时的给定（创始人原话，2026-11-01）**：「我们的重点是管理咨询关系。」对标心理咨询——核心资产是关系本身；形态是入口，lite 提供一个轻的，studio 提供更完整的。

未来态——关系管理到什么程度算够、lite/studio 各自要长成什么样、什么时候算这个域成了——**待创始人给定，AI 不代配**。

## 规矩

1. **意图只写「要到哪去」**：不写路径、不写指标——路径归 `data/roadmap`；
2. **创始人给定**：AI 可以从日志与档案里整理候选表述供创始人挑，不许代配、不许外推市场想象；
3. **岔路问答校验**：意图每被引用一次做取舍，对不上就改表述、不改人；
4. **快照式**：更新是替换，不并存；
5. **当验收标尺，不参与论证**：路线图做完一格回头用意图验；意图不由路线图推导、不由洞察支撑。

## 与 insight、roadmap 的对账

路线图两头对账：向上用本仓的意图验收，向内用 `data/insight` 的洞察验证实况。洞察塌了改洞察、重排路线图；意图对不上只有创始人判得了。

| 整理候选表述 | agent | 从接触记录与档案里整理，供创始人挑，不代配 |
